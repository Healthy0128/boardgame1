# BOARD TABLE

スマホ・タブレット・PCの1台を共有して2人で遊ぶ、3ゲーム入りのボードゲームコレクションです。

## Games
- リバーシ: 合法手表示、パス、勝敗判定、スコア
- チェス: 基本合法手、チェック、チェックメイト、キャスリング、アンパッサン、プロモーション
- 将棋: 基本駒移動、捕獲、持ち駒、駒打ち、成り、二歩制限

## Controls
- タップ / クリックで駒を選択
- 「待った」で1手戻す
- 「盤を回す」で対面プレイ向けに180度回転
- スマホ、タブレット、PCのレスポンシブ表示に対応
- PWA用マニフェストとサービスワーカーを同梱

## Assets
将棋は Shogi Images、チェスは Sashité のCC0素材を表示に使用しています。
